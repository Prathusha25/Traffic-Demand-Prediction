# 🚦 Traffic Demand Prediction – Flipkart HackerEarth Hackathon

## 📌 Overview

This project was developed as part of the **Flipkart HackerEarth Hackathon** to predict traffic demand using **Machine Learning** and **Feature Engineering** techniques.

The model analyzes traffic-related parameters and predicts demand patterns for better traffic management and decision-making.

---

## 🎯 Problem Statement

Predict traffic demand using factors such as:

✔️ **Geographical Location (Geohash)**  
✔️ **Road Type**  
✔️ **Weather Conditions**  
✔️ **Number of Lanes**  
✔️ **Vehicle Information**  
✔️ **Timestamp Data**  
✔️ **Environmental Factors**

---

## ⚙️ Features Implemented

### 🔹 Data Preprocessing

✔️ **Missing Value Handling**  
✔️ **Data Cleaning**  
✔️ **Categorical Feature Processing**

### 🔹 Feature Engineering

✔️ **Hour Extraction from Timestamp**  
✔️ **Peak Traffic Hour Detection**  
✔️ **Cyclical Time Encoding (Sin/Cos Transformation)**  
✔️ **Traffic Pattern Feature Creation**  
✔️ **Temperature × Number of Lanes Interaction Features**

### 🔹 Machine Learning Techniques

✔️ **CatBoost Regressor**  
✔️ **K-Fold Cross Validation**  
✔️ **Hyperparameter Tuning**
